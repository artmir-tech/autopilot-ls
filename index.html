Опора «Код»

Не просто работающий код, а чистый

Код пишется по ub-mode — стандарту Роберта Мартина, автора книги «Чистый код». Это не наш инструмент: мы встроили его в работу. Каждый ИИ-исполнитель и каждый ревьюер загружает его первым делом.

Через месяц так же быстро, как в первую неделю.

Новая функция добавляется за дни, а не продирается через завалы.

Правка не ломает старое.

Тесты сразу замечают, если что-то перестало работать.

Понятен другому.

Разработчику-человеку или следующему ИИ: проект не привязан к одному исполнителю.

Восемь правил, по которым пишет ИИ-исполнитель

Сначала тест.

Каждый новый тест сначала должен упасть — иначе он ничего не проверяет.

Сначала работает, потом красиво.

Порядок наводится отдельным шагом, а не «потом как-нибудь».

Меньше, а не больше.

Прежде чем добавить, убрать лишнее.

Невозможное невозможно.

Запись без времени не может появиться даже по ошибке: так устроены данные.

Проверка на входе.

Всё, что пришло снаружи, проверяется один раз — там, где вошло.

Повтор не ломает.

Дважды нажатая кнопка не создаст две записи.

Причина, а не симптом.

Ошибку чинят там, где она возникла, а не прячут.

Тесты про поведение.

Проверяют то, что видит пользователь, поэтому не ломаются от каждой перестановки.

Это правила для ИИ. Результат проверяет машина: тестами и тремя проверками выше.

Как начать

1

Установи Claude Code.

Это программа от Anthropic, в которой ИИ пишет код на твоём компьютере. Нужна подписка Claude: Pro за $20, чтобы попробовать, Max или Ultra для проектов на недели.

2

Поставь автопилот.

Проверено на Mac. Нужны Python 3 и git: если их нет, Mac сам предложит поставить. Две команды в терминале:

git clone -b ls https://github.com/artmir-tech/autopilot-ls
cd autopilot-ls && tools/install-ls.sh
Не работал с терминалом? Открой Claude Code и напиши ему: «Поставь навык autopilot-ls: склонируй github.com/artmir-tech/autopilot-ls и запусти tools/install-ls.sh». Он сделает всё сам и спросит разрешения.

Ставится только на компьютер. С телефона сохрани ссылку на эту страницу.

3

Расскажи идею.

В Claude Code напиши /autopilot-ls и дальше своими словами, что хочешь получить.

Под капотом — для разработчиковЧто ставится, что делает с git, кто что проверяет, как остановить

Что ставится

Копия навыка в ~/.claude/skills/autopilot-ls/ и навык ub-mode в ~/.claude/skills/ub-mode/, если его ещё нет. Настройки, хуки и права доступа Claude Code установка не трогает. Удалить: rm -rf ~/.claude/skills/autopilot-ls.

Что появляется в проекте

Папка .autopilot/: бриф, требования, план, учёт и страница проекта. Строки в .gitignore. AGENTS.md, если своего файла памяти нет. Твой CLAUDE.md автопилот не правит, а только предлагает дополнения.

Git

Каждый исполнитель работает в своём git worktree и своей ветке. В твою текущую ветку задача попадает только перемоткой (--ff-only) после зелёной проверки. Ничего не пушит без твоего «да». Откат — git revert серии коммитов задачи: коммиты помечены прогоном и требованиями.

Кто что проверяет

  • Скрипт ap.py: учёт, больше ста отказов идти дальше, запуск тестов, итог оценки архитектуры, лицензии через GitHub.
  • Программы: CRAP, дубли, мутации.
  • Claude: исполнители, ревьюеры, архитектор и критики, слепая приёмка, новичок.
  • Другие компании: только если сам включишь судью диалогов из другой модели.

Остановить и продолжить

Останови чат когда угодно. /autopilot-ls без слов продолжит с того же места: всё состояние лежит в файлах, а не в памяти чата.

Ночью работает локальная запланированная задача приложения Claude Code. Она создаётся только с твоего согласия, режим прав выбираешь ты. На первом сбое ночь останавливается. Расход пятичасового окна и недели берётся из приложения, после 85 % новое не запускается.

Вопросы и ответы

Нужно ли уметь программировать?

Нет. Ты рассказываешь, отвечаешь на вопросы и принимаешь результат. Код пишет и проверяет ИИ. Даже установку можно поручить самому Claude Code.

Что такое «чистый код» и зачем он мне, если я не программист?

Чистый код легко менять. Через месяц новая функция добавляется так же быстро, как в начале, и правка не ломает то, что уже работало. Ты видишь это по скорости и по тому, что ничего не отваливается.

Сколько это стоит?

Автопилот бесплатный, код открыт. Нужна подписка Claude: Pro за $20 в месяц хватит, чтобы попробовать, но работа будет часто ждать сброса лимита. Для проектов на недели — Max за $100 или Ultra за $200. Если продукт должен работать круглосуточно, добавится аренда сервера.

Что можно построить?

Телеграм-бота, сайт, веб-сервис — то, что работает как программа. Большой продукт делится на этапы по несколько дней.

Сколько времени это займёт?

От нескольких часов до нескольких недель. Срок покажет план, который ты получишь в начале.

А если ИИ ошибётся?

Ошибётся, и не раз. Поэтому каждую задачу проверяют тесты, важные — отдельный ревьюер, а в конце — независимая приёмка по твоим словам. Что не получилось, честно попадает в отчёт.

Куда уходят мой код и данные?

Код видит Claude — так же, как при обычной работе в Claude Code: это сервис компании Anthropic. Сам автопилот больше никуда его не отправляет. Поиск готового ищет на GitHub по названию задачи, а не по твоему коду. Модель другой компании подключается, только если ты сам включишь ею проверку диалогов. Пароли и ключи автопилот не запрашивает и не записывает.

Можно оставить его работать ночью?

Да, если разрешишь. Ночью он берёт только задачи, которым не нужны твои решения, и останавливается на первом сбое, чтобы не наломать дров. Утром — отчёт. Компьютер при этом включён, а приложение Claude Code открыто.

Нужно ли держать компьютер включённым? Где будет работать готовый бот?

Пока идёт сборка — да, всё строится на твоём компьютере. Готовый бот или сайт, чтобы работать круглосуточно, выкладывают на сервер: это отдельная недорогая аренда. Наружу автопилот ничего не выкладывает без твоего «да».

Работает на Windows?

Проверено на Mac. На Linux должно работать так же. Windows пока не проверяли.

Подойдёт для уже существующего проекта?

Да. Сначала автопилот изучит код и запишет, как он устроен, и только потом начнёт планировать.

Чем это отличается от обычного Claude Code?

Claude Code — умный исполнитель. Автопилот — процесс вокруг него: план, роли, проверки, память между сессиями и страница проекта.

Расскажи идею — план, код и проверки автопилот возьмёт на себя.

  • План на недели. Несколько этапов, график, страница проекта и страница решений.
  • Разговор о людях. Для кого продукт, и проход глазами новичка в конце.
  • Ночную очередь. Работа без тебя и утренний отчёт.
  • Проверку промптов и диалогов. На примерах, со сравнением со старой версией и судьёй из другой модели.
Изменили
  • Модель под задачу. Своя модель и усилие у каждой задачи, сильнее — если не вышло с первого раза.
  • Своя копия кода. Каждый исполнитель работает в отдельной копии (git worktree) и сдаёт только свои файлы.
  • «Готово» решает скрипт. Тесты запускает он, а не исполнитель.
  • Риск, а не только размер. Если задача касается денег, доступов или данных, поиск готового и проверку архитектуры не пропустить, даже если она маленькая.
Улучшили
  • Чистый код. Стандарт ub-mode Роберта Мартина и автоматические пороги сложности, повторов и силы тестов.
  • Бережнее к лимиту. Темп по пятичасовому окну и неделе, пауза до того, как лимит кончится.
  • Строже к правилам. Больше ста мест, где скрипт учёта отказывается идти дальше; решения владельца — только его словами.
  • Спецификацию. Запреты, крайние случаи (пусто, длина, повтор) и пункты, которые без теста не засчитываются.
